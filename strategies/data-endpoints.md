## Endpoints needing attention

- **`benzinga` / `analyst_actions` — auth (HTTP 403)**: `https://api.benzinga.com/api/v1/analyst/insights`
- **`gdelt` / `news_sentiment` — rate_limited (HTTP 429)**: `https://api.gdeltproject.org/api/v2/doc/doc`
- **`moomoo` (19 rows)** — all `gateway`: the provider is SDK-shaped (`moomoo://{sdk_method}`), served over
  the local OpenD gateway rather than HTTP. Reachability is verified separately by TCP-connecting
  `MOOMOO_HOST:MOOMOO_PORT`; the five interpretive category mappings were confirmed against a live
  `OpenQuoteContext` (see `finrobot_desktop/docs/DATA_PROVIDERS_V3_IMPLEMENTATION.md` §9.7).

### Two probe-vs-production defects found and fixed while producing this snapshot

1. **`federal_reserve` could never fetch.** The Treasury daily-yield-curve CSV needs ~17s; both the probe
   and the adapter used a 15s timeout, so the risk-free curve always failed. Both are now 45s, and a test
   pins the probe timeout to be >= the slowest adapter.
2. **The probe reported a false `http 307` for `cboe`.** The adapter follows cdn.cboe.com's redirect to
   cdn-api.cboe.com; the probe did not. The probe client now follows redirects, and this snapshot shows
   that row as `ok`.
